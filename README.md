# Neon Roguelike

Первый играбельный прототип 2D-рогалика на **Godot 4**. Графика генерируется кодом, поэтому внешние ассеты не нужны.

## Что уже работает

- движение на WASD или стрелки;
- прицеливание мышью и стрельба на ЛКМ;
- враги преследуют игрока и становятся быстрее со временем;
- здоровье, смерть и перезапуск забега;
- усиление урона, скорострельности и лечение каждые 8 убийств;
- постепенное увеличение сложности.

## Запуск

1. Установить [Godot 4](https://godotengine.org/download/).
2. Импортировать файл `project.godot`.
3. Нажать **F6** или **F5**.

## Ближайший план

- выбор одного из трёх улучшений после волны;
- разные типы врагов;
- рывок и активная способность;
- комнаты и переходы между ними;
- первый босс;
- мета-прогрессия между забегами.
